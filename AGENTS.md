## Agent skills

### Development workflow

Before planning, changing files, running experiments, publishing artifacts, or
resuming work, read `docs/agents/development-workflow.md` for human approval
boundaries and the development overview entry point.

### Issue tracker

Use GitHub Issues. Read `docs/agents/issue-tracker.md` when working with tickets or specs.

### Triage labels

Use the five default triage roles. Read `docs/agents/triage-labels.md` when triaging or applying labels.

### Domain docs

Use a single-context layout. Before exploring the codebase, read `docs/agents/domain.md`.
