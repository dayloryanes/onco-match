# OncoMatch

An AI-assisted oncology clinical study matching proof of concept.

## Technology Stack

- Backend: ASP.NET Core / .NET 10
- Frontend: React, TypeScript, Vite
- Clinical study source: ClinicalTrials.gov
- Local AI inference: Ollama

## Project Structure

- `backend/` — ASP.NET Core API and automated tests
- `frontend/` — React application

## Status

Initial project scaffolding complete. POC 1 development pending.
